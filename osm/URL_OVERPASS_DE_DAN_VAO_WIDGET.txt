GHI CHU
  - KHONG dung openstreetmap.org: ten mien do bi chan DNS tren may nay.
    Overpass API tra ve dung dinh dang .osm XML nen thay the duoc.
  - Dinh dang bbox = <trai>,<duoi>,<phai>,<tren> = minlon,minlat,maxlon,maxlat
  - O "Select OSM Database" la danh cho file .osm tai san - CHI CHAY TREN LINUX.
    Tren Windows bat buoc dung o "OSM URL".
